# PCM Gassen – app mobile

App instalável (PWA) de manutenção da linha de abate do Frigorífico Gassen.
Os dados ficam na planilha Google do PCM; o app conversa com ela por um serviço do Google Apps Script.

- Funciona sem internet: peças, imagens e lançamentos ficam guardados no celular e são enviados quando a conexão volta.
- Acesso por ID e senha. O cadastro é feito só pelo administrador, na aba "Usuários app" da planilha (protegida pela conta Google dele).
